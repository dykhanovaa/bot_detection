**Главная идея сбора признаков:**

Бинарная классификация cookie на основе агрегированных поведенческих признаков.

События каждой cookie сначала ограничиваются её временным окном и сортируются по времени. Затем из последовательности действий строятся признаки, описывающие:

* количество и доли типов событий;
* разнообразие объявлений, категорий, запросов и локаций;
* повторяемость действий;
* глубину и последовательность поиска;
* интервалы между событиями;
* сессии пользователя;
* временную плотность активности;
* pointer/mouse-поведение;
* платформу и User-Agent;
* последовательности переходов между событиями;
* популярность объявлений и поисковых запросов.

Для классификации используется HistGradientBoostingClassifier. Валидация проводится по времени, то есть модель для каждого validation-периода обучается только на более ранних данных. Для итогового предсказания используется ансамбль моделей с разными random_state, а их вероятности усредняются.

Основная метрика — P@Recall ≥ 0.7, дополнительно считаются PR-AUC и ROC-AUC.
